# PM3-Infinity 🚀
This is a custom, high-performance distribution of ProcessMaker 3.8. 

### Main Goals:
* **PHP 8.1 Support**: Fully compatible with modern environments.
* **Modern UI**: Moving away from legacy styles to a clean, responsive interface.
* **Security**: Updated third-party libraries via Composer.
* **Speed**: Optimized database queries and caching.
